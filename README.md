# Taller de Algoritmoa

Astrid Daniela Jaramillo Madrid

## Descripción
En este repositorio está la solución del taller en Java visto en la materia de Algoritmos II.

## Estructuras implementadas
- Array
- Lista enlazada
- Pila
- Cola
- Lista doblemente enlazada

## Organización
El proyecto lo organicé  en la carpeta src, donde cada estructura tiene su propia carpeta con su código y su clase Main para hacer las pruebas.

## Notas
Implementé los métodos solicitados y hice pruebas en cada estructura para verificar su funcionamiento.
No realicé commits intermedios. Se me presentaron algunos errores pequeños en la implementación, pero los identifiqué y  los corregí, dejando el proyecto funcionando correctamente.
